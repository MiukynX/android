# Fitness App

Flutter-приложение для фитнес-клуба.

## Возможности
- Расписание тренировок
- Список моих тренировок
- Новости фитнес-клуба
- Профиль пользователя
- Отслеживание тренировок

## Технологии
- Flutter
- Dart

## Запуск
1. Установите Flutter.
2. Выполните `flutter pub get`.
3. Запустите приложение командой `flutter run`.
